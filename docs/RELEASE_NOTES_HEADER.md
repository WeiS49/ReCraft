## Install

Requires an Apple Silicon Mac running macOS 26 or later, and your own Claude or OpenAI API key.

1. Download `ReCraft-<version>.zip` below, unzip it and move `ReCraft.app` to `/Applications`.
2. Open it. This build is not notarized by Apple, so macOS blocks the first launch: go to **System Settings → Privacy & Security**, scroll down and click **Open Anyway**.
3. Grant Accessibility when asked, then enter your API key under **Settings… → API Key**.

After updating to a newer release, macOS treats the app as a new one: remove the old ReCraft entry under **Privacy & Security → Accessibility** and add it again. See the [README](https://github.com/WeiS49/ReCraft#install) for details and known limits.
